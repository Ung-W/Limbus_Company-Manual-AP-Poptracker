# Limbus Colpany (Manual) Poptracker for Archipelago

> Tracker created by Evoker (Me) using StripesOO7's [Pack Builder](https://github.com/StripesOO7/poptracker-pack-builder)

This is a Poptracker pack for Limbus Company's [Manual AP Implementation](https://github.com/Ung-W/Limbus_Company-Manual_AP) by Evoker (Me) and designed by EchoingEito

## Version compatibility
The version of a given tracker is given following this pattern : x.y.z
- x means that this version is compatible with all apworld x.?.?
- y means the season of limbus that it has been released on
- z is the an arbitrary update number

for exemple, Tracker v4.9.5 means that the tracker:
- Is compatible with 4.x.x apworlds
- Released during season 9
- Is the 5th release of a tracker update since the start of that season

## Functionalities

As [Universal Tracker](https://github.com/FarisTheAncient/Archipelago/releases/latest) already takes care of the manual's tracking accessible locations component, this Tracker is more a "what can I equip tracker"

> Reminder : You have to receive every keyword needed for a given ID's kit to be able to use it, same goes with EGO

### ID Tracker

- Red means that you can't equip this ID
- Green means that you can equip this ID
- Yellow means that you can equip this ID, technically shouldn't be able to but up to you
  - Specifically for LCB Don Quixote and Tingtang Hong Lu : it technically has a keyword attached to it that you don't have, but the inflictions are so minimal that the dev / designer deemed unneccesary to limit it


### EGO Tracker

- Red means that you can't equip this EGO
- Green means that you can equip this EGO
- Yellow means that you can equip this EGO, technically shouldn't be able to but up to you
  - Specifficaly for "Suddenly, One day" Gregor and "Holiday" Heathcliff : The EGOs inflicts random keywords so the dev/designer didn't know how to classify them, you can use them as soon as you want to (only need 1 of the keywords attached to it)
